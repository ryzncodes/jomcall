# JomCall — agent handover

The product name is **JomCall**. Use `JomCall` in user-facing text and `jomcall` (or `jomcall_`, `JOMCALL_`) in code identifiers.

It answers Malaysian SMEs' phone calls and WhatsApp messages 24/7 with an AI agent that speaks the caller's language (BM, English, Manglish, Mandarin), answers questions, books appointments, takes messages and transfers to staff. Inbound is the core business; outbound lead follow-up is secondary. Delivered as a hosted self-serve SaaS (MYR billing) with the full code public under FSL-1.1-ALv2 (source-available; each release converts to Apache-2.0 after two years).

## Frontend work: how to start

- Stack per spec: Next.js + TypeScript (`web` service). UI component library, auth provider and payment provider are open decisions (spec §10); pick sensible defaults and note them, or ask the owner.
- Keep server-selected modes isolated: mock preview at 4181 uses existing fictional browser data; local app at 4182 uses named commands from `packages/contracts/src/core.ts`. Never fall back to mock records on a local error. Unsupported integrations stay explicitly unavailable. Read root `README.md`, `infra/local/README.md` and the Phase 1 spec/plan before backend work. All runtime services stay local unless the owner explicitly changes that constraint. One exception was approved by the owner on 2026-11-13: the agent's language model may be a hosted model through OpenRouter when `JOMCALL_MODEL_PROVIDER=openrouter` is set (see `packages/inference/src/provider.ts`). It is opt-in, off by default, and only the agent worker holds the key. Do not add other outbound calls on the strength of that exception. Three more exceptions were approved by the owner on 2026-11-13, for the spoken path only. Each is opt-in. The switch `JOMCALL_VOICE_PROVIDER=hosted` gates the agent's turn endpoint and the web command that starts a call (default off). The voice worker, `npm run voice:prewarm` and `npm run check:voice-speed -- --prepare` do not read it: running them sends fixed or fake text to Google. The three services: Deepgram speech to text (`nova-3`, multilingual), key `DEEPGRAM_API_KEY`, used only by the voice worker; Anthropic API direct for the spoken brain (`claude-haiku-5-5`), key `ANTHROPIC_API_KEY`, used only by the agent process; Google Gemini text to speech (`gemini-3.8-flash-lite-tts`, Agent Platform endpoint), key `GOOGLE_CLOUD_API_KEY`, used only by the voice worker. All keys live in the gitignored `.env.hosted`. This is not permission for any other outbound call. The LiveKit server itself runs locally (Docker, loopback only). The turn-detector model stays uninstalled: `livekit-agents` is pinned at 1.6.0 because 1.6.1 through 1.8.11 require (checked) `livekit-local-inference` (LiveKit Model License).
- Start with the screens that decide whether an owner trusts the product: guided setup with browser test call, agent test panel, call log (see `docs/frontend/screens.md`).

## Rules

- **Original work only.** Write everything from scratch. Do not copy code, endpoint paths, schemas, names, prompts, copy text or assets from other products.
- **No secrets in git.** Keys go in local `.env` files only (gitignored). Never print or commit keys or tokens.
- **No personal data in git.** No real call audio, transcripts or customer data; use clearly fake sample data (fake names, fake numbers).
- **Malaysia first.** UI in BM and English; amounts in MYR (store as integer sen); times in `Asia/Kuala_Lumpur`; phone numbers in E.164; mobile-first, because owners check calls on their phones.
- **Compliance is visible in the UI:** AI and recording disclosure setting, consent records, do-not-contact switch, PDPA export and delete.
- **License:** FSL-1.1-ALv2 (see `LICENSE.md`). Only add dependencies whose licenses allow use in commercial, source-available software (MIT, Apache-2.0, BSD, ISC and similar). Avoid GPL/AGPL dependencies. One exception, accepted by the owner on 2026-11-13: the voice service may use LiveKit's turn-detector model under the proprietary LiveKit Model License. It is optional, is not redistributed here, and the service must work without it. Open, awaiting the owner's decision (found 2026-11-14): the Python voice worker's dependency `av` (BSD-3-Clause, required by livekit-agents) ships a wheel that bundles FFmpeg built with libx264 and libx265 (GPL-2.0-or-later); JomCall does not redistribute these binaries, but they are loaded at runtime.
- Commits: small, Conventional Commits style. Work on a feature branch, not `main`.
